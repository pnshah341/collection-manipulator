🐍 Student Data Organizer — Python Project

Collection Manipulator

A beginner-friendly Python project that manages student records using Python collection data types and basic programming concepts.

📌 Project Overview

The Student Data Organizer is a menu-driven Python program that allows users to add, display, update, and delete student records. It also displays all unique subjects offered by students.

This project demonstrates the practical use of Python Lists, Tuples, Sets, Dictionaries, String Formatting, Type Casting, and the "del" keyword.

🎯 Objectives

- Store and organize student information.
- Perform basic operations on student records.
- Understand Python collection data types.
- Practice mutable and immutable data types.
- Apply loops and conditional statements.
- Use string methods and formatting techniques.

✨ Features

- ➕ Add Student: Enter student ID, name, age, grade, date of birth, and subjects.
- 📋 Display Students: View student records in a readable format.
- ✏️ Update Student: Modify a student's age or grade.
- 🗑️ Delete Student: Remove a student record using their ID.
- 📚 Display Subjects: Show unique subjects without duplicates.
- 🚪 Exit: Close the program with a thank-you message.

🛠️ Technologies Used

- Language: Python 3
- Editor: Python IDLE / VS Code
- Platform: Windows or any system with Python 3

📖 Python Concepts Used

Concept| Purpose

1. List| Store multiple student records
2. Tuple| Store student ID and date of birth as fixed information
3. Set| Store unique subjects
4. Dictionary| Organize student details using student IDs
5. "input()" and "print()"| Accept and display information
6. Type Casting| Convert age input into an integer
7. String Formatting| Display formatted student details
8. "if-elif-else"| Handle menu choices
9. "while" loop| Repeat the menu
10. "for" loop| Display students and subjects
11. "del" keyword| Delete a student record
12. String Methods| Format and clean subject names

🚀 How to Run

1. Install Python 3 on your computer.

2. Download or clone this repository.

3. Open the project folder in Python IDLE or VS Code.

4. Run the Python file:
   
   python Project3.py

5. Select an option from the menu and follow the instructions.
